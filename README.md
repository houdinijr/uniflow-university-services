# UniFlow — University Services Management Concept

UniFlow is an early-stage responsive website prototype for a university student-services management system. It explores a shared portal for submitting and tracking requests, reviewing them in service teams, and improving visibility.

## Prototype status
This repository contains a **front-end concept prototype**, not a production system. It has no authentication, backend, database, real university records, notifications or live integrations. Dashboard data is illustrative sample data.

## Run locally
Open `index.html` in a browser. No build tools are required. Alternatively run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Publish with GitHub Pages
1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to show the published address.
